# Contributing to IntelliSTAR Emulator

Thank you for your interest in contributing! This project is optimized for Chrome only.

## How to Contribute

### Reporting Issues
- Check if the issue already exists
- Provide a clear description
- Include steps to reproduce
- Specify your Chrome version
- Attach screenshots if applicable

### Submitting Changes
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Test in Chrome (all other browsers will display a warning)
5. Commit your changes (`git commit -m 'Add amazing feature'`)
6. Push to your branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

## Chrome Compatibility
All features must be tested in the latest version of Google Chrome. Webkit-specific properties are preferred where applicable.

## Code Style
- Use consistent indentation (2 spaces)
- Use semantic HTML
- Comment complex JavaScript logic
- Keep CSS organized by component

## Commit Messages
Be descriptive in commit messages:
- ✨ `:sparkles:` New feature
- 🐛 `:bug:` Bug fix
- 🔧 `:wrench:` Configuration changes
- 📝 `:memo:` Documentation
- ⚡ `:zap:` Performance improvement
- 🎨 `:art:` UI/styling changes

## Pull Request Process
1. Update CHANGELOG.md with your changes
2. Ensure all changes work in Chrome
3. Include descriptive commit messages
4. Request review from maintainers
5. Address feedback and make requested changes

## Questions?
Open an issue with the `question` label or contact the maintainer.

Thanks for contributing! 🎉
